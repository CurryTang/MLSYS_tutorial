# Math：快速幂与拒绝采样 / Binary Exponentiation & Rejection Sampling

数学与离散概率题不是靠死记硬背公式，而是把一个大问题拆解为可按位迭代的二进制结构，或构造等概率的离散映射空间。

本章涵盖两个高频核心面试模型：

1. **快速幂（Binary Exponentiation）**：LeetCode 50: `Pow(x, n)` —— 通过二进制按位拆分，将 $O(n)$ 的乘法开销压缩到 $O(\log n)$。
2. **拒绝采样（Rejection Sampling）**：LeetCode 470: `Implement Rand10() Using Rand7()` —— 解决不同基数随机数生成器间的等概率映射、非整除空间的截断与重采样。

## Problem 1：Pow(x, n)（快速幂）

### 题目

给定浮点数 `x` 和整数 `n`，返回 `x^n`。

例子：

```text
Input:  x = 2.00000, n = 10
Output: 1024.00000
```

```text
Input:  x = 2.00000, n = -2
Output: 0.25000
```

因为：

```text
2^-2 = 1 / 2^2 = 1 / 4
```

### 为什么不能暴力乘 n 次

最直接的做法是：

```python
ans = 1
for _ in range(n):
    ans *= x
```

这需要 `O(n)` 次乘法。如果 `n = 2^31 - 1`，这个做法太慢甚至会超时。

快速幂的目标是把复杂度降到：

```text
O(log n)
```

核心原因是：

```text
x^10 = x^(8 + 2)
```

而 `10` 的二进制是：

```text
10 = 1010₂ = 8 + 2
```

所以我们不需要一个一个乘 `x`，只需要判断哪些二进制位是 `1`。

### 核心直觉

每一轮维护两个变量：

```text
base = 当前这一位代表的幂
res  = 已经选中的幂的乘积
```

从右往左看 `n` 的二进制位。

对 `n = 10 = 1010₂`：

```text
bit 权重: 8 4 2 1
bit 值:  1 0 1 0
```

从最低位开始看：

```text
1 的位置不选
2 的位置选
4 的位置不选
8 的位置选
```

所以：

```text
x^10 = x^2 * x^8
```

这就是为什么代码里有两件事：

```python
if power & 1:
    res *= x
```

最低位是 `1`，说明当前 `x` 这份幂需要乘进答案。

然后：

```python
x *= x
power >>= 1
```

`x *= x` 表示当前幂翻倍：

```text
x^1 -> x^2 -> x^4 -> x^8 -> ...
```

`power >>= 1` 表示把二进制最低位丢掉，继续看下一位。

### 可视化：为什么是 res *= base，然后 base *= base

```pow-demo
```

把 `pow(2, 10)` 展开：

```text
10 = 1010₂
```

我们从右往左读 bit。

| 当前 power | 最低位 | 当前 base | 动作 | res |
|---|---:|---:|---|---:|
| 10 | 0 | 2 | 不乘，base 平方 | 1 |
| 5 | 1 | 4 | 乘进 res | 4 |
| 2 | 0 | 16 | 不乘，base 平方 | 4 |
| 1 | 1 | 256 | 乘进 res | 1024 |

最后：

```text
res = 4 * 256 = 2^2 * 2^8 = 2^10
```

### 迭代实现（Iterative Binary Exponentiation）

#### Algorithm
1. 如果 `x == 0`，返回 `0`。
2. 如果 `n == 0`，返回 `1`。
3. 令 `res = 1`。
4. 令 `power = abs(n)`。
5. 当 `power > 0`：
   - 如果 `power & 1` 为真，执行 `res *= x`；
   - 执行 `x *= x`（底数平方）；
   - 执行 `power >>= 1`（右移一位）。
6. 如果原 `n < 0`，返回 `1 / res`；否则返回 `res`。

#### Python 代码

```python
class Solution:
    def myPow(self, x: float, n: int) -> float:
        if x == 0:
            return 0
        if n == 0:
            return 1

        res = 1
        power = abs(n)

        while power:
            if power & 1:
                res *= x
            x *= x
            power >>= 1

        return res if n >= 0 else 1 / res
```

#### 复杂度
- **时间复杂度**：$O(\log |n|)$，每轮循环将 `power` 右移 1 位，循环次数严格等于 $\lfloor \log_2 |n| \rfloor + 1$。
- **空间复杂度**：$O(1)$，仅需常数级额外变量。

#### 快速幂常见坑
1. **忘记处理负指数**：如果直接 `power = n` 且 `n < 0`，位移与循环条件会出错。必须先取 `abs(n)` 并在最后根据符号取倒数。
2. **位运算与优先级的混淆**：`power & 1` 用来判断最低位是否为 1，等价于 `power % 2 == 1`，但位运算更高效。
3. **`x == 0` 与负指数边界**：数学上 $0^{-1}$ 未定义（Division by Zero），LeetCode 题目保证不会出现该非法输入，但在工程实现中应加入防御性断言。

## Problem 2：Implement Rand10() Using Rand7()（拒绝采样）

### 面试目标

这类题的代表是 LeetCode 470：`Implement Rand10() Using Rand7()`。

题目：

```text
已知 rand7() 可以等概率返回 1..7。
实现 rand10()，要求等概率返回 1..10。
```

核心方法是 **rejection sampling（拒绝采样）**。

在面试中要能讲清楚三件事：

- 多次调用 `randM()` 可以构造一个更大的均匀整数笛卡尔空间。
- 不能直接 `% N`，除非空间大小能被 `N` 整除。
- 截取能被 `N` 整除的最大前缀，剩下的样本丢掉重采样（保持条件概率均匀）。

### 标准解：rand7 实现 rand10

调用两次 `rand7()`：

```python
x = (rand7() - 1) * 7 + rand7()
```

这会等概率生成 `1..49`。

为什么是均匀的？第一次 `rand7()` 决定行（0..6），第二次 `rand7()` 决定列（1..7）：

```text
7 x 7 = 49 个格子
```

每个格子的概率都是：

```text
1/7 * 1/7 = 1/49
```

所以 `x` 在 `1..49` 上严格均匀分布。

但 `49` 不能被 `10` 整除。如果直接 `x % 10`，会导致有些结果出现 5 次，有些结果出现 4 次，破坏均匀性。

因此只保留 `1..40`：

```text
40 能被 10 整除
1..40 里每个 rand10 结果刚好出现 4 次
41..49 丢掉，重新采样
```

代码：

```python
class Solution:
    def rand10(self) -> int:
        while True:
            x = (rand7() - 1) * 7 + rand7()  # uniform 1..49
            if x <= 40:
                return (x - 1) % 10 + 1
```

注意返回值写成 `(x - 1) % 10 + 1`，这样结果落在 `1..10`，而不是 `0..9`。

### 为什么不能直接取模

假设我们直接把 `1..49` 模 10 映射到 `1..10`：

```text
1, 11, 21, 31, 41 -> 1
2, 12, 22, 32, 42 -> 2
...
9, 19, 29, 39, 49 -> 9
10, 20, 30, 40    -> 10
```

前 9 个结果各出现 5 次，结果 `10` 只出现 4 次。

概率分别是：

```text
P(1..9) = 5/49 ≈ 0.1020
P(10)   = 4/49 ≈ 0.0816
```

这违反了均匀分布要求。

拒绝采样的本质：**只在概率能完全均分的区间取结果，利用条件概率 $P(A \mid A \in \text{valid}) = \frac{1/49}{40/49} = \frac{1}{40}$ 保持每个输出的绝对公平。**

### 通用模板：randM 实现 randN

如果有 `randM() -> uniform 1..M`，想实现 `randN() -> uniform 1..N`：

1. 用 `k` 次 `randM()` 构造一个足够大的均匀空间 `1..M^k`（满足 $M^k \ge N$）。
2. 找到最大整除界限 `limit = floor(M^k / N) * N`。
3. 如果采样值 `x <= limit`，返回 `(x - 1) % N + 1`。
4. 否则拒绝，重新采样。

通用代码模板：

```python
def randN():
    while True:
        x = 1
        for _ in range(k):
            x = (x - 1) * M + randM()

        limit = (M ** k // N) * N
        if x <= limit:
            return (x - 1) % N + 1
```

### 怎么选择 k

最简单的规则：**选最小的整数 $k$，使得 $M^k \ge N$。**

例如 `rand7 -> rand10`：
- $7^1 = 7 < 10$
- $7^2 = 49 \ge 10$
所以用两次 `rand7()`。

接受与拒绝概率：
```text
usable = floor(49 / 10) * 10 = 40
accept = 40 / 49 ≈ 81.63%
reject = 9 / 49 ≈ 18.37%
```

每次成功所需的平均轮数（几何分布期望）：
```text
E[rounds] = 1 / accept = 49 / 40 = 1.225
```
每轮调用两次 `rand7()`，所以期望调用次数为：
```text
2 * (49 / 40) = 2.45 次
```

### 变形一：优化 rand10，复用被拒绝的随机性

标准解丢弃了 `41..49`。但这 9 个数在发生拒绝的前提下，本身在 `1..9` 上依然是完全均匀的！我们可以将这 9 个数复用，与新的一次 `rand7()` 组合，形成 `9 * 7 = 63` 的均匀空间：

```python
class Solution:
    def rand10(self) -> int:
        while True:
            # 步骤 1：利用两次 rand7 产生 1..49
            x = (rand7() - 1) * 7 + rand7()
            if x <= 40:
                return (x - 1) % 10 + 1

            # 步骤 2：x 属于 41..49（共 9 个数），映射为 1..9 后与 rand7 组合成 1..63
            x = (x - 40 - 1) * 7 + rand7()  # uniform 1..63
            if x <= 60:
                return (x - 1) % 10 + 1

            # 步骤 3：x 属于 61..63（共 3 个数），映射为 1..3 后与 rand7 组合成 1..21
            x = (x - 60 - 1) * 7 + rand7()  # uniform 1..21
            if x <= 20:
                return (x - 1) % 10 + 1
            # 若落在 21，则重新进入 while 循环
```

优化后的期望调用次数从 2.45 降至约 2.19 次。在面试中，先给出标准解，再主动提出该优化，能展现深厚的随机算法素养。

### 变形二：rand5 实现 rand7

$5^1 = 5 < 7$，$5^2 = 25 \ge 7$。
`limit = floor(25 / 7) * 7 = 21`。

```python
def rand7():
    while True:
        x = (rand5() - 1) * 5 + rand5()  # 1..25
        if x <= 21:
            return (x - 1) % 7 + 1
```

### 变形三：rand2 实现 rand3

两次 `rand2()` 生成 `1..4`，`limit = 3`：

```python
def rand3():
    while True:
        x = (rand2() - 1) * 2 + rand2()  # 1..4
        if x <= 3:
            return x
```

### 变形四：rand10 实现 rand7（大转小）

若原空间已经大于目标空间（$M \ge N$），单次采样直接截断即可：

```python
def rand7():
    while True:
        x = rand10()
        if x <= 7:
            return x
```

### 变形五：用 randM 生成任意连续区间 [a, b]

目标区间长度 $N = b - a + 1$。先用模板生成 `randN()`（范围 `1..N`），再平移：

```python
def randRange(a: int, b: int) -> int:
    return randN() + a - 1
```

### 变形六：偏置硬币实现公平抛掷（Von Neumann Trick）

如果给定的随机源本身不是等概率的（例如一枚出现正面的概率为 $p \neq 0.5$ 的偏置硬币），则不能直接套用笛卡尔积。

解决办法是冯·诺伊曼策略（Von Neumann Trick）：连续抛掷两次硬币：
- 若结果为 `(正面, 反面)`，概率为 $p(1 - p)$；
- 若结果为 `(反面, 正面)`，概率为 $(1 - p)p = p(1 - p)$；
- 二者概率严格相等！因此令 `(正, 反) -> 0`，`(反, 正) -> 1`；
- 若出现 `(正, 正)` 或 `(反, 反)`，则舍弃并重新抛掷。

这一技巧将任意未知概率的偏置布尔生成器转换为完美的公平硬币（Fair Coin）。

### 正确性证明

1. **样本空间均匀性**：$k$ 次独立的 `randM()` 笛卡尔积包含 $M^k$ 种等可能的基本事件，因此构造出的整数 $x$ 在 $[1, M^k]$ 上严格服从均匀离散分布。
2. **条件概率均等**：取 $limit = \lfloor M^k / N \rfloor \times N$。在 $x \le limit$ 的条件事件下：
   $$P(x = v \mid x \le limit) = \frac{P(x = v)}{P(x \le limit)} = \frac{1 / M^k}{limit / M^k} = \frac{1}{limit}$$
3. **映射均匀性**：映射函数 $f(x) = ((x - 1) \pmod N) + 1$ 将大小为 $limit$ 的集合均等地分为 $N$ 份，每份大小为 $limit / N$。因此对任意目标值 $y \in [1, N]$：
   $$P(f(x) = y \mid x \le limit) = \frac{limit / N}{limit} = \frac{1}{N}$$
4. **拒绝不引入偏置**：当 $x > limit$ 时，样本被直接丢弃并进入独立同分布的下一次试验，不会在任意输出点上积累概率倾斜。

因此输出结果严格服从 $[1, N]$ 上的均匀离散分布。

### 复杂度总结

对 `rand7 -> rand10`：
- 接受概率：$P_{\text{accept}} = 40 / 49$
- 期望调用次数：$2 \times \frac{49}{40} = 2.45$
- 空间复杂度：$O(1)$

### 常见坑
- 直接 `% N`，忽略了母集大小无法被 $N$ 整除所带来的概率偏倚。
- 忘记 `randM()` 的取值是从 1 开始，在计算多进制展开时漏减 1（正确公式为 `(x - 1) * M + randM()`）。
- 误用 `(x % N) + 1` 作为返回值，当 $x$ 为 $N$ 的倍数时会输出 $0 + 1 = 1$，应统一写成 `(x - 1) % N + 1`。
- 担心拒绝采样会陷入死循环：只要接受概率 $p > 0$，运行轮数服从几何分布，期望运行轮数有限，以概率 1 在有限步内终止。

这道题不能直接对 `rand7()` 的输出进行取模，因为 7 或 49 不能被 10 整除，直接取模会使部分余数出现的频率比其它余数多一次，从而破坏均匀性。

标准做法是拒绝采样（Rejection Sampling）：
1. 连续调用两次 `rand7()` 构造一个大小为 49 的离散均匀空间：
   `x = (rand7() - 1) * 7 + rand7()`
2. 找到 49 以内能被 10 整除的最大整数 40。只接受 $x \le 40$ 的采样值；
3. 对于接受的值，通过 `(x - 1) % 10 + 1` 均匀映射到 `1..10`；
4. 对于 $41..49$ 的 9 个数，直接拒绝并重新采样。

在 $1..40$ 的有效区间内，每个数字对应到 $1..10$ 的次数均为 4 次，由条件概率公式可知每个输出的概率严格为 $1/10$。平均调用次数为 $2 \times (49/40) = 2.45$ 次，空间复杂度为 $O(1)$。
